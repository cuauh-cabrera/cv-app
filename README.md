## 💻 Getting Started <a name="getting-started"></a>

### Prerequisites

- **[ Node.Js]**
- **[ Git ]**

### Setup

Clone this repository to your desired folder:

Example commands:

```sh
  cd your-local-folder
  git clone https://github.com/cuauh-cabrera/cv-app.git
```

### Install

Install the project on your local mahcine using any code editor and run:

```sh
  npm run install
```

```sh
  npm run dev
```

### Usage

Open the project using a code editor and deploy the project on your local computer.
